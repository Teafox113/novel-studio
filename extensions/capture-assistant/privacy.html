素材收集助手：資料使用說明

更新：2026-11-12 · 開發者 FloofyFox

保存什麼

使用者主動收集的文字、網頁標題、來源網址、收集時間，以及自行輸入的便條與未送出草稿。勾選附上來源時會取得目前網頁網址。

資料放在哪裡

存在本機瀏覽器設定檔的擴充功能儲存空間。不會自動上傳、販售、追蹤、建立雲端帳號或同步到 Google Drive。開發者無法透過此工具讀取你的素材。匯出的 JSON 由你決定保存或分享的位置。

移除與保留

素材可逐筆刪除。草稿可清空輸入框；刪除擴充功能會清除本機素材與草稿。已下載的匯出檔及已匯入編輯器的內容是獨立副本，須在各自位置管理。請在移除前先匯出備份。

來源與權限

只在你使用右鍵收集或開啟助手時取得必要資料。沒有背景網頁掃描。來源網址可能含私人參數，分享前請檢查。摘錄不授予轉載、改作或商業使用權。

聯絡與更新

可透過 GitHub Teafox113/novel-studio 的 Issues 聯絡開發者；公開回報時請勿貼上私人稿件或網址。未來若新增網路或雲端功能，會先更新說明並提供明確的啟用選擇。
