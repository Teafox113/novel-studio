# Novel Studio 素材收集助手 · 0.1.0 本機原型

網頁上反白文字、按右鍵「收進 Novel Studio 素材匣」，保留原文、標題、來源網址與收集時間。工具列彈出視窗可新增自己的便條、搜尋、刪除及匯出全部素材。

此版本尚未送審 Chrome Web Store。需要搭配 **2026-11-05 的 Novel Studio 開發版**；GitHub v0.18.0 安裝版沒有素材匯入功能。

## 本機試用

1. 在 Chrome 開啟 `chrome://extensions`，開啟「開發人員模式」。
2. 按「載入未封裝項目」，選取本資料夾（內有 `manifest.json`）。
3. 在擴充功能清單釘選收集助手；到一般 HTTP／HTTPS 網頁反白文字後按右鍵收集。
4. 開啟助手，確認素材出現在清單。需要記靈感時，在「隨手便條」輸入文字。
5. 按「匯出全部」，確認下載的 JSON 存在。匯出不會清除原始素材。
6. 在 Novel Studio 開發版按「⋯ → 匯入瀏覽器素材」，選擇 JSON，預覽並勾選要匯入的內容。
7. 摘錄可在「研究」查看；個人筆記可在右下角「便條紙」查看。等作品顯示已儲存後再退出。

相同素材 ID 再次匯入會略過，不會覆蓋已整理的內容。重新收集同一段文字會產生新的 ID，視為另一筆素材。刪除收集匣內容不影響已匯入的作品；移除擴充功能會清除收集匣，請先匯出。

便條輸入時會在本機記住未送出的草稿，關閉助手後可以繼續寫。草稿尚未列入匯出內容，請先按「收進素材匣」。

## 資料與權限

- `contextMenus`：建立使用者主動點選的右鍵收集選項。
- `storage`：把素材存於此瀏覽器設定檔的本機空間；不是 Chrome Sync。
- `activeTab`：使用者開啟助手或點選右鍵項目時，取得當前頁面的來源資訊。不要求全部網站的持續讀取權限。
- 沒有內容腳本、背景爬取、分析追蹤、遠端執行程式碼、帳號登入或網路上傳。
- 網址可能含私人查詢參數；匯出／分享前請檢查來源與摘錄是否含敏感內容。
- 最多 200 筆或 4 MB；單筆文字 20,000 字。超出限制會提示，不會截斷原文。請確認已匯入再刪除舊素材。
- 收集匣不是備份系統。瀏覽器資料清除或移除擴充功能可能造成資料遺失。

## 測試與限制

在專案根目錄執行 `npm test` 可測試格式、容量限制與桌面匯入邏輯，`npm run build` 驗證桌面前端編譯。

2026-11-05 已在隔離 Edge 設定檔側載原型，測試真實擴充服務背景程序、草稿重新載入、筆記儲存、搜尋、JSON 下載、取消刪除及匯出檔的桌面前端匯入。測試未涵蓋 Chrome 工具列小視窗的實機互動、原生右鍵選單點擊、升級與解除安裝；仍需人工驗收，不能視為商店上架驗證。

目前不支援自動同步、直接傳送桌面程式、全文爬取、圖片附件、Chrome 內建頁面或 PDF 檢視器。商店送審、正式圖示、公開隱私政策頁、無障礙與實機側載驗收仍待完成。

收集是研究與私人寫作工具；來源文章與網站素材仍由原權利人持有，收集並不授予轉載或商業使用權。此原型採自行撰寫的 HTML／CSS／JavaScript，未引入新的第三方執行期依賴。整體產品授權與第三方權利審查仍以正式發布前確認為準。
