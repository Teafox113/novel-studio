# AI 協作與本機審核

Novel Studio 0.7.0 的 AI 協作中心先採規則式本機分析。它不需要 API 金鑰，也不會
把正文、人物或研究資料傳送到網路。

## 能檢查什麼

- 沒有摘要的場景：從正文開頭產生摘要候選。
- 人物年齡：辨識「人物名稱＋數字＋歲」並提出世界觀屬性候選。
- 年齡矛盾：同一人物出現不同年齡，或正文與世界觀屬性不一致。
- 本文提及：正文出現人物、地點或其他實體名稱，但場景尚未建立連結。
- 缺少 POV 或主要地點的場景。
- 尚未填寫故事內時間的時間事件。
- 同一名稱或別名指向多筆世界觀資料。

規則只能提出候選，不能理解所有語境。例如「十年前他二十歲」需要結合事件時間
推理，目前仍可能需要作者自行判斷。

## 審核流程

1. 進入「AI 協作」，按「開始本機分析」。
2. 依矛盾、注意、建議或資料類型篩選結果。
3. 查看說明、來源場景引文及預計變更。
4. 按「採用變更」才會寫入場景摘要、人物屬性或場景連結。
5. 不適用的結果可按「略過」。沒有自動動作的警告則使用「完成審閱」。

接受與略過都會保存時間及穩定指紋。重新掃描時，相同項目不會再次回到待審核區。

## 資料安全邊界

- 掃描完全在目前裝置執行。
- 不會修改正文段落。
- 不會自動接受候選。
- 略過不會改動任何故事資料。
- 重複採用同一本文提及不會建立重複連結。
- 審核紀錄包含在 `.novel` 匯出檔及本機快照中。

## 後續方向

未來可選擇接入雲端或本機語言模型，用於章節摘要、世界觀問答與複雜時間推理。
即使接入模型，結果仍必須轉成相同的候選、證據、差異與人工核准流程。
