# 人物狀態卡

從「世界觀」選擇人物，在基本資料上方可看到狀態卡。既有人物與新增人物都適用，不會自動為角色添加物品或數值。

## 操作

1. 在身分、身體狀態、背包、已知資訊、能力或數值旁按＋。
2. 輸入關鍵字，例如「左腿受傷」「黃銅鑰匙」「密道入口」。
3. 背包可設定非負整數數量；能力與數值可填目前值及選填上限。有上限時會顯示進度條，值須介於零與上限之間；無上限的數值可為負數。
4. 可以選擇既有世界觀資料，名稱會跟著該資料更新。選「獨立關鍵字」可解除連結。
5. 可指定來源場景、補充取得原因或解除條件。按「儲存關鍵字」後納入專案自動儲存；取消會捨棄尚未儲存的編輯。
6. 點關鍵字可重新編輯、查看世界觀或來源場景。離開編輯前請先儲存。移除後可立即按「復原移除」，離開人物頁後可使用專案備份還原。

搜尋框會搜尋目前人物的關鍵字名稱與說明。人物既有摘要、別名、自訂屬性與關係仍保留在下方。連結目標移除時，原關鍵字保留，並提示重新選擇。

## 作者設定與劇情狀態

此版是作者手動管理的設定卡，不代表任何特定分支遊玩的即時状态。你可記錄初始設定或構想，但不同路線不要混成同一份「當前背包」。

尚未實作：句旁註記轉變數、分支畫布、選項條件、自動套用取得／消耗效果、逐場景狀態及試走回退。後續會以獨立遊玩狀態承接，保留作者初始設定。

## 備份與升級

狀態卡會隨本機儲存、快照、專案副本及 .novel 匯入匯出保留。資料格式升為 schema v8，請用 0.14.0 或更新版本開啟；不要以舊版覆寫含人物卡的作品。升級前請匯出 .novel 備份。
