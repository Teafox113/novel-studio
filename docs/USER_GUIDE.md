# Novel Studio 使用指南

## 1. 選擇下載檔案

到 [Releases](https://github.com/Teafox113/novel-studio/releases/latest) 選擇：

| 檔案 | 適合誰 | 使用方式 |
| --- | --- | --- |
| Windows-x64-Setup.exe | 一般使用者 | 執行安裝，從開始功能表開啟 |
| Windows-x64-zh-TW.msi | 使用 MSI 部署的環境 | 執行 Windows Installer |
| Windows-x64-NoInstall.zip | 不想安裝主程式 | 完整解壓後執行 Novel-Studio.exe |
| SHA256SUMS.txt | 需要核對下載完整性 | 與 Get-FileHash 的 SHA256 比較 |

免安裝版仍需要 Microsoft Edge WebView2 Runtime。Windows 未具備時，請先安裝 Microsoft 官方 WebView2 Runtime，或使用會處理執行環境需求的 Setup 版。安裝檔目前未簽署數位簽章，Windows 可能提示來源未驗證。

**免安裝不代表資料跟著 EXE 移動。** 安裝版與免安裝版使用相同應用程式識別，會使用同一 Windows 帳號下的本機資料目錄。請勿同時開啟兩個版本編輯，以免互相覆寫。搬到另一台電腦請使用 .novel 匯出／匯入。

## 2. 建立自己的小說

1. 首次啟動會出現「霧港十三夜」示範作品。
2. 右上角「⋯」→「我的小說專案」。
3. 填寫小說名稱與作者，按「新建空白小說」。
4. 從「第一章」开始寫作；在手稿側欄新增後續場景。
5. 等右上角顯示「已儲存」。

## 3. 切換與另存作品

「我的小說專案」會列出目前裝置上保存的作品。點作品名稱可切換；切換前先保存目前作品並建立安全快照。儲存失敗會顯示錯誤，留在原作品。

若想試寫不同走向，填寫副本名稱後按「目前作品另存副本」。新副本有不同專案識別，保留目前內容及素材，後續修改互不影響；原作品仍在清單中。舊快照不複製到新作品。

「另存副本」保存於本機作品庫；需要實體檔案請使用「匯出專案」。目前不支援直接綁定 .novel 檔持續寫回、作品刪除或多裝置同步。

## 4. 寫作與參考資料

- 「編輯」撰寫正文，「卡片」整理場景摘要，「大綱」查看全稿。
- 「打字機」進入專注模式；Esc 返回。
- 「研究」新增筆記、網址或附件，再到寫作區開啟「研究浮窗」。
- 專注模式浮窗可選四個角落，也可以收合。
- Ctrl+K 搜尋全文；Ctrl+Shift+R 切換研究浮窗。
- 右上版本按鈕查看更新紀錄與下載入口。

## 5. 備份、還原與跨電腦

1. 「⋯」→「匯出專案」，保存 .novel 檔，內含手稿與內嵌素材。
2. 將該檔複製到另一台電腦，在新電腦選「匯入專案」。
3. 匯入相同專案識別會更新該作品內容，不會自動產生獨立副本。要分支請先另存副本。
4. 「備份與還原」→「比較」可查看備份與目前內容的差異，確認後再還原。
5. 每次升級前都建議匯出一份 .novel；本機快照不等於異地備份。

瀏覽器資料依瀏覽器與網址分開儲存。請勿清除網站資料後才尋找作品；附件較多時可能達到 localStorage 容量上限，建議使用 Windows 版。

## 6. 匯出書稿

左側「匯出」可選擇場景與稿件狀態，預覽後輸出 DOCX、EPUB、HTML 或文字；PDF 透過系統列印另存。書稿匯出與 .novel 專案備份用途不同，前者不含完整創作資料庫。

## 7. 升級與問題回報

關閉舊版後安裝新版，或解壓新版 ZIP 到新資料夾。不要刪除使用者資料目錄。出現問題時，提供版本、Windows 版本、操作步驟與錯誤訊息到 GitHub Issues；請勿上傳私人稿件。

## 8. 架空歷史與曆法

左側「架空歷史一覽」可設定紀元、月長與週日，並將事件依虛構日期排列。請參閱 [架空歷史操作指南](FICTIONAL_HISTORY.md)。新版資料格式為 schema v7；含曆法的專案應使用 0.12.0 或更新版本開啟。
