# 在另一台電腦使用 Novel Studio

## 安裝

一般 Windows 10／11 使用者建議使用：

```text
release/Novel-Studio-0.9.0-Windows-x64-Setup.exe
```

安裝程式會安裝在目前的 Windows 使用者帳號，不需要系統管理員權限。
若 Windows 顯示 SmartScreen 警告，是因目前測試版尚未購買程式碼簽章憑證；
請只使用本專案資料夾內產生的安裝檔。

企業環境或需要 MSI 部署時，可使用：

```text
release/Novel-Studio-0.9.0-Windows-x64-zh-TW.msi
```

## 搬移小說

### 原電腦

1. 等待右上角顯示「已儲存」。
2. 按右上角三點按鈕，開啟「專案與備份」。
3. 選擇「匯出專案」。
4. 將產生的 `.novel` 檔存到 USB 或個人雲端硬碟。

### 新電腦

1. 安裝並開啟 Novel Studio。
2. 按右上角三點按鈕。
3. 選擇「匯入專案」並選取 `.novel` 檔。
4. 確認作品名稱後完成匯入。

匯入前，Novel Studio 會先替新電腦上原有的內容建立「匯入前備份」，避免覆蓋
後無法復原。

## 備份與還原

- 程式每天第一次開啟既有作品時，最多建立一份自動備份。
- 可隨時按時鐘圖示建立手動快照。
- 「專案與備份 → 備份與還原」會列出本機版本與字數。
- 還原舊版本前，程式會再保存一份「還原前備份」。
- 瀏覽器模式最多保留二十份快照；桌面模式目前列出最近三十份。

## 目前限制

- `.novel` 檔需由使用者手動複製；尚未提供即時雲端同步。
- Windows 安裝版只支援 x64 電腦。
- macOS、Linux、Android 與 iPhone 尚未發布。
- `.novel` 目前只包含小說結構與文字；未來加入的圖片、PDF 及音訊會再納入封裝。
