# Novel Studio 0.10.0

發布日期：2026-09-11。Windows x64 桌面版。

## 本次更新

- 打字機專注模式：暖色紙張、深色書房、游標行跟隨與 Esc 返回。
- 專注模式研究浮窗：四角定位、收合，參照筆記、圖片與 PDF。
- 快照版本比較：新增、刪除、修改統計，以及備份與目前內容的欄位對照。
- 右上角「FloofyFox · v0.10.0」版本資訊：功能、更新紀錄、資料保存說明與 GitHub 入口。
- 建置腳本改為使用目前使用者的 Rust 路徑。

## 安裝與更新

一般使用者下載 `Novel-Studio-0.10.0-Windows-x64-Setup.exe`；需要 MSI 部署時使用 `.msi`。兩者擇一即可。

更新前先在舊版「專案與備份」匯出 `.novel`，關閉程式後執行安裝包。本版沿用資料庫識別與 schema v6，不新增資料格式遷移。

安裝程式尚未簽署數位簽章，Windows 可能顯示 SmartScreen 提示。請確認來源為本專案 Releases；可利用 `SHA256SUMS.txt` 核對檔案完整性。

## 已知限制

- 浮窗採四角定位，尚無任意拖曳及多份文件並排。
- 版本比較是欄位級對照，尚無逐字標色或選擇性合併。
- 本機審核使用規則分析，尚未串接大型語言模型。
- 尚無跨裝置即時同步，請定期匯出專案備份。
- 中文實體輸入法、PDF 原生預覽與不同 Windows 環境仍需更多實機驗證。
