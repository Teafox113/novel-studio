# 編號劇情塊與基本試讀

0.17.0 支援文字選項、編號跳轉、變數條件與選擇後效果。人物卡同步、自動分流、句旁註記及連線圖尚未接入。

## 開始使用

1. 先在手稿建立至少兩個場景並寫好正文。
2. 開啟左側「互動書籍」，勾選「互動分支模式」。場景會取得 #001、#002 等固定編號，手稿側欄也會顯示。
3. 點選劇情塊。需要時按「設為起點」。初次開啟會自動指定第一個場景。
4. 「讓讀者選擇」：按「＋新增選項」，輸入文字並選目標編號。多個選項可以指向同一塊。
5. 「直接繼續」：指定目標，試讀時按「繼續閱讀」前往。
6. 「在此結束」：設定結局，不顯示後續選項。
7. 將分支檢查中的待設定項目補齊，按「從起點開始試讀」。所有現有場景都需有選項、繼續目標或標為結局。

亦可按「編輯這一塊的正文」，直接在手稿下方的「接下來」設定相同選項。設定自動儲存。按「查看目標」可開啟目標正文；移除選項後可立即復原。

## 編號規則

編號與手稿順序分開。移動場景不改號，新增場景取得下一個未使用編號；被移除的編號不重用。選項透過固定場景 ID 連結，場景改名仍連到原目標。若目標被移除，會提示重新指定，不能開始新的試讀。

關閉互動模式只會隱藏編號與互動欄位，保留全部設定。切換選項／直接繼續／結局也保留之前的選項，只執行目前選定方式。

## 試讀

可選不同選項、回退一步或重新開始，也可展開已走過的編號路徑。這版顯示純文字正文，不呈現所有富文字樣式。

試讀使用開始時的內容快照，不修改正文或人物卡。修改分支後，留在工作區的試讀會提示重新開始；離開互動工作區會結束這次試讀。試讀進度目前不保存，重新開啟時需從起點開始。

每次跳轉都需讀者按選項或「繼續閱讀」，支援返回先前場景；不會無限自動跳轉；取得物品或數值變化只在點選已設定效果的選項後執行。

## 保存與升級

分支設定納入本機儲存、專案快照比較、副本與 .novel 匯入匯出。資料格式為 schema v9，請以 0.15.0 或更新版開啟，不要使用舊版覆寫。升級前先匯出備份。

## 0.17.0：選項條件與變化

先到變數庫將物品、資訊、數值或狀態設為「已設定」，再展開選項的「條件與變化」。所有條件都符合才可選擇；變化只在點選選項後依序執行。沒有條件的選項預設可選。

例如：鑰匙初始值設為 1，進門選項設定「鑰匙至少 1」，並在選擇後「鑰匙增加 −1」。試讀時會消耗鑰匙，回退一步則還原消耗。物品不足會停用選項，避免負數。資訊／狀態使用 1 和 0，僅支援設值。

試讀保留獨立的變數狀態，不修改作者初始值或人物卡。修改變數後請重新開始試讀。直接繼續與結局不執行選項效果；切换模式仍保留原設定。尚未實作人物卡同步、逐句效果或自動分流。含規則的專案請勿用舊版試讀，舊版不會執行條件與效果。
