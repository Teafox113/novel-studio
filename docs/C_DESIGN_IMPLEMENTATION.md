## 實作範圍與相容性

保留八個 Section 值與資料模型，外層分成寫作／設定／成書。介面採明體名稱、黑體操作、石灰桌面、稿紙、行線綠與印泥紅；色票獨立於模組佈局。沒有加入網路字型、外部美術資產或新的執行期套件。

便條使用現有 InspirationItem 與 linkedNodeIds；選文建立便條會保存摘錄及場景連結，但不宣稱段落位置會隨文字移動。舊便條仍可選取／回收／復原。每日新增統計沒有可靠歷史來源，先只顯示本場與選取字數。匯出頁是實際內容預覽，不宣稱瀏覽器高度就是精確印刷分頁。

## 權利與雲端評估：採納與修正

- **同名產品已核對**：[Openapps-free 原專案](https://github.com/Openapps-free/novel-studio) 的公開頁面確有同名小說軟體。這是辨識混淆風險，並非已證實侵權。商標、發表先後及程式來源的法律判斷仍未完成；新名稱與自身授權由作者決定。
- **不直接修改 identifier**：桌面資料路徑與更新可能依識別碼而定。改品牌顯示名稱與搬資料是兩件事；若要改 identifier，先做舊路徑偵測、備份與可回復遷移測試。
- **MPL 不只管修改**：[Mozilla FAQ Q8](https://www.mozilla.org/en-US/MPL/2.0/FAQ/) 說明，散布自行編譯的未修改 MPL 元件也需告知原始碼取得處。先區分打包內容與純建置依賴，再附來源與必要聲明；不能只憑 MIT 多數就保證整體無風險。
- **商店單一用途**：[Chrome 政策](https://developer.chrome.com/docs/webstore/program-policies/policies) 要求清楚用途、必要權限與資料揭露，並不據此推導「所有編輯器與收集功能必須分成兩個商品」。本產品選擇助手獨立是範圍與品質決策。
- **Drive 最小權限**：[drive.file](https://developers.google.com/workspace/drive/api/guides/api-specific-auth) 適合由程式建立或使用者授權的檔案；選了某資料夾不等於整個既有子樹全部自動可讀，必須實測 Picker／共用資料夾邊界。
- **無後端登入可行**：[桌面 OAuth](https://developers.google.com/identity/protocols/oauth2/native-app) 支持原生程式流程，但仍需 Cloud 設定及用戶端 ID。權杖進 OS 安全儲存；未完成前不新增 Google 權限。
- **同步不是寫個鎖檔就安全**：Drive 多檔寫入沒有本產品可依賴的跨檔原子交易；狀態檔只作協作提示。先用修訂／內容雜湊與衝突副本設計，再決定分場景儲存。
- **推播與共編區分**：[Drive 推播](https://developers.google.com/workspace/drive/api/guides/push) 需要 HTTPS 接收端；純客戶端可輪詢。逐字共編需另外設計通訊與合併，不將「必定需要自建伺服器」當唯一解法，也不承諾 Drive 直接提供。
- **CSP 已配置、待原生驗收**：依 [Tauri CSP](https://v2.tauri.app/security/csp/) 限制包內腳本、IPC、圖片與 PDF 附件。樣式保留 inline 以支援編輯器與動態版面；未開放任何 Google 網域。瀏覽器開發伺服器不等於 Tauri 生產 CSP 驗收。

另外於實際畫面驗收修正高倍率縮放的雙重縮小，以及新建作品重新開啟時未選中正文的問題；驗證結果與截圖見 [畫面驗收](../design-qa.md)。

以上是工程與產品規劃，不是零侵權或商店核准保證。後續順序與驗收條件見 [ROADMAP](ROADMAP.md)。
