# Novel Studio 0.13.0 — 字型與獨立縮放

- 新增介面與小說正文各自的字型選擇。
- 介面支援 100%、110%、125%、150%、175% 縮放。
- 正文字級 15～36px，不受應用程式介面縮放影響。
- 一般寫作與打字機模式均可直接調整正文字級。
- 放大手稿清單、世界觀卡片與側欄的小字，設定自動保留。

選左側「設定 → 顯示與字級」開始調整。字型依電腦安裝情況回退；這是裝置顯示偏好，不改變匯出書稿排版。

## 下載與升級

一般使用者下載 Setup.exe；免安裝選 NoInstall.zip，完整解壓後執行 Novel-Studio.exe。免安裝版需 WebView2 Runtime，資料保存在 Windows 使用者目錄，與安裝版共用，請勿同時編輯。升級前先匯出 .novel 備份。安裝包尚未簽署數位簽章。

## 驗證

56 項自動測試、前端建置與 Windows 原生建置通過；瀏覽器已檢查縮放、獨立字型與打字機字級控制。尚未在乾淨 Windows 完成安裝驗收。資料格式維持 schema v7。
