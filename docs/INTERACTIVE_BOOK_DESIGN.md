# 互動書籍設計規劃：編號劇情塊

更新：2026-09-18。依作者回饋簡化，取代前版的複雜流程設計。本文件為整體規劃。0.15.0 已完成第一階段的模式開關、編號、文字選項、跳轉、基本試讀與回退；其他階段仍未實作。現有基礎包括 0.14.0 人物狀態卡。操作方式見 [互動書籍指南](INTERACTIVE_BOOK.md)。

## 核心操作

開啟「互動分支模式」→ 劇情塊顯示編號 → 寫選項並指定目標編號 → 按試讀查看結果。

一般小說繼續照原本方式寫作。互動模式可隨時關閉，僅隱藏互動欄位，不刪除已有設定。

## 劇情塊與跳轉

沿用既有手稿場景作為第一版的劇情塊，不另外複製正文。每塊有固定編號及名稱，例如「#001 舊書店」「#002 鐘塔門口」。編號與手稿排序分開，移動場景不改號；新塊自動給下一個未使用編號，刪除後不自動把舊號交給另一塊。底層仍以穩定 ID 保護連結。

互動模式下，每塊正文下方增加「接下來」區域：

- 直接繼續：選擇目標，例如 → #002 鐘塔門口。
- 讓讀者選擇：新增選項文字，每項選擇目標編號。
- 結束：標記此處為結局。

目的地可輸入編號或搜尋名稱，點目標標籤即可跳去編輯。多個選項指向同一編號，就是劇情匯合，不需要另一種匯合節點。刪除被引用的塊時列出受影響選項；失效連結明確提示，不暗中跳至其他塊。

範例：

#001 舊書店
正文：桌上放著一把黃銅鑰匙。
選項：拿走鑰匙 → #002（得到黃銅鑰匙 ×1）
選項：直接離開 → #002

#002 鐘塔門口
選項：用鑰匙開門 → #003（需要持有黃銅鑰匙）
選項：返回書店 → #001
選項：離開霧港 → #004

#003 密道：後續劇情。
#004 離開霧港：結局。

拿走鑰匙的選項可設為每次試讀只選一次，避免反覆領取。

## 簡單的條件與變化

每個選項預設只需「文字＋跳往編號」。需要時才展開兩個附屬欄：

| 欄位 | 例子 |
| --- | --- |
| 出現／可選條件 | 持有鑰匙、知道暗號、體力至少 30 |
| 選擇後的變化 | 得到藥水、消耗鑰匙、得知資訊、體力減少 10 |

第一版提供物品數量、資訊已知／未知、數值及狀態標籤。使用人物卡既有關鍵字或新建，不要求作者輸入程式碼。多項條件以「全部符合／任一符合」選擇，不提供任意巢狀公式。

需要自動分流時，在「直接繼續」加上簡單規則：「若持有鑰匙 → #003，否則 → #004」。多條規則依列表順序取第一個符合者，最後必填「其他情況」。無需獨立判斷節點。

條件不符可選隱藏，或顯示但不能按。試讀的作者檢查區可查看原因。物品不足或數值非法時不執行整組變化。可設定效果只發生一次或每次到達都發生。

## 句旁註記

寫作區右側「情節註記」可開關。選取原句後記下自由文字，例如「知道密道位置」。註記卡按「設為互動變化」，選擇人物、關鍵字、變化與發生時機。

發生時機先提供：「讀到這段後」或「選擇某選項後」。例如選擇不讀信的人不應獲得信中資訊；不能將所有註記一律在進入劇情塊時執行。

原句與註記保留連結。文字移動時跟隨，原句刪除或無法辨認時標示「待重新指定」，不猜測套用到另一句。再次轉換同一註記應編輯既有變化，避免重複。純筆記不參與試讀運算。

## 人物卡與試讀

作者設定保留為初始資料；試讀另開一份狀態，不覆寫人物設定。現有人物卡可能含作者構想，因此由作者勾選哪些項目作為初始值。

試讀畫面顯示當前劇情塊與選項，旁邊可開啟人物卡，查看目前背包、已知資訊、身體狀態及數值。用簡短提示呈現「得到鑰匙」「體力 65 → 45」。提供重新開始、回退一步、返回目前劇情塊編輯。

回退同時恢復物品、資訊、數值與只觸發一次的記錄。兩条路都跳到 #003 時，各次試讀沿用自己的經歷，不混合背包。第一版從指定起點試讀，測試存檔與修改後自動重播後續再做。

## 分支一覽

左側「互動書籍」集中顯示劇情塊列表：編號、名稱、可前往哪些編號、是否為起點或結局。點編號即可開啟。先把這個列表及編輯器內跳轉做順手。

連線圖作為後續的輔助總覽，自動依編號跳轉關係產生；作者不必先畫圖才能寫故事。以後可支援拖線選擇目的地，但仍編輯同一份跳轉設定。

## 開發順序與驗收

1. 模式開關、固定編號、目標選擇、選項、起點／結局與基本試讀。
2. 接上人物關鍵字、簡單條件與變化、回退及當前人物卡。
3. 句旁註記與轉變化、來源定位。
4. 自動分流、分支列表與輔助連線圖。

每階段都可獨立使用，不先建立龐大規則系統。所有資料納入專案保存、備份與匯入匯出。

以「拿／不拿鑰匙 → 是否能開門」驗收完整流程；追加已知資訊及體力條件。確認重新進入不重領一次性物品、回退完整還原、重排不改跳轉、移除目標有提示、儲存重開設定仍在。自動跳轉循環需能中止並標出出錯編號。
