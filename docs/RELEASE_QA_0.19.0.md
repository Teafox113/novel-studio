# v0.19.0 發布驗收

日期：2026-11-24。所有測試使用示範／專用驗收作品；開始原生驗收前，另存既有 SQLite 檔至忽略版控的本機 release 目錄。

## 自動測試

- `npm test`：27 個測試檔、128 項通過。
- `npm run build`：TypeScript 與正式前端建置通過。
- `npm run test:schema`：6 份 SQLite migration、15 個應用資料表檢查通過。
- `scripts/run-cargo.ps1 test --manifest-path src-tauri/Cargo.toml --locked`：4 項原生測試通過。

| 風險 | 驗證 |
| --- | --- |
| 兩個新版同時寫入 | OS 檔案鎖拒絕第二個 handle；第一個關閉後可重新取得 |
| 磁碟滿造成半份備份 | 原生測試在寫入前 10 bytes 後注入 StorageFull；舊檔內容不變、半檔移除 |
| 未完成檔案被列為備份 | `.partial` 不進入歷史清單 |
| 目的地不存在或是一般檔案 | 拒絕寫入，既有檔案不變 |
| 路徑越界與 Windows ADS | 拒絕 `../`、替代資料流檔名及資料夾外路徑 |
| 還原另一部作品 | 先快照目前作品與目標作品；兩者都成功才儲存還原內容 |
| 快照或還原失敗 | 第一／第二份快照失敗均停止；儲存錯誤向上傳遞，不改輸入內容 |
| 瀏覽器備份清單損壞 | 不以空清單覆寫，原始資料保留 |
| Drive 離線 | 測試失敗目的地重試、成功目的地不重複；介面明確區分資料夾寫入與雲端確認 |
| 舊儲存晚於還原 | 既有序列化測試確保舊儲存先完成；佇列錯誤後可繼續 |

## 建置環境

## 驗證邊界

錯誤注入測試不是破壞性斷電／真實磁碟填滿實驗，也不代表已驗證 Google 遠端服務。尚未提供備份自動清理、瀏覽器跨分頁鎖或新舊版本混用保護。舊版不認得新版寫入鎖，升級前須關閉舊版。真實繁中輸入法候選字與長時間寫作仍需人工持續測試。
