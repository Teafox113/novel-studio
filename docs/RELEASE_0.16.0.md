# Novel Studio 0.16.0 — 關鍵詞快速收集與變數庫

- 正文反白後右鍵加入互動變數，立即存成待設定並繼續寫作。
- 同名沿用、連結既有變數，以及搜尋／狀態篩選。
- 可稍後補齊類型、人物、初始值與說明，保存草稿或完成設定。
- 淡底線標記可關閉，變數庫保留原句並可定位回正文；引用失效會提示。
- 保存、備份、專案副本及快照比較包含變數庫與引用。

使用：[變數庫操作指南](https://github.com/Teafox113/novel-studio/blob/main/docs/WRITING_VARIABLES.md)。不需先開啟互動分支模式。

本版為收集與設定管理，尚未接入人物卡或試讀條件／效果運算；提及物品不會自動取得。細節設定需按儲存，快速收集自動保存。

## 下載與升級

Setup.exe 為安裝版；NoInstall.zip 完整解壓後執行 Novel-Studio.exe。免安裝版需 WebView2，資料保存在使用者目錄，與安裝版共用。安裝檔尚未簽章。

升級前先匯出 .novel 備份。新版 schema v10 需使用 0.16.0 或更新版本，勿以舊版覆寫。

73 項自動測試與 SQLite schema 驗證通過；隔離瀏覽器驗證右鍵／鍵盤收集、焦點返回、同名合併、設定保存、重新載入與來源定位／失效提示。尚未完成乾淨 Windows 安裝驗收。
