# Novel Studio 0.15.0 — 編號劇情塊與互動試讀

- 左側新增互動書籍，開關互動模式而不刪除設定。
- 手稿場景取得固定編號，移動不改號、刪除不重用。
- 文字選項跳轉、直接繼續、起點與結局設定；正文下方亦可編輯。
- 分支設定檢查、從起點試讀、回退、重新開始及路徑查看。
- 分支資料納入本機儲存、備份比較、專案副本與 .novel 交換。

這是第一階段。人物條件、物品／資訊變化、句旁註記、自動分流與連線圖尚未實作。試讀顯示純文字且不保存進度，不更動人物卡。參考 Inky／Ink 的概念，未整合 Ink 技術或格式。

## 使用

「互動書籍 → 互動分支模式」，選劇情塊、填選項與目的編號，設定結局後從起點試讀。詳見 [操作指南](https://github.com/Teafox113/novel-studio/blob/main/docs/INTERACTIVE_BOOK.md)。

升級前請匯出 .novel 備份；新版 schema v9 需以 0.15.0 或更新版本開啟，勿以舊版覆寫。

下載 Setup.exe 安裝，或將 NoInstall.zip 完整解壓執行 Novel-Studio.exe。免安裝版需 WebView2，資料仍在 Windows 使用者目錄並與安裝版共用。安裝包尚未簽章。

68 項自動測試及 SQLite schema 驗證通過。隔離瀏覽器驗證模式開關、兩路結局、回退、重開保存、移除復原與正文內編輯均通過。尚未完成乾淨 Windows 安裝驗收。
