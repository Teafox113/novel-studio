# 架空歷史一覽

左側「架空歷史一覽」管理世界的虛構曆法與事件年代。它與「時間線」共用事件：歷史一覽依虛構日期排序；原時間線保留故事順序及閱讀順序，互不強制重排。

## 設定世界曆法

1. 按「設定曆法」，填入曆法名稱與紀元，例如「霧港曆」「建城」。
2. 月份欄每行填「名稱,天數」，例如 `霧月,30`、`潮月,28`。每年可有 1–48 個月，每月 1–1000 日。
3. 週日名稱以逗號分隔，例如「晨日,潮日,暮日」，可有 1–30 日。
4. 按「儲存曆法」。如果新月長使既有日期無效，系統會拒絕修改；先修正相關事件再修改曆法。

紀元 1 年首日對應第一個週日名稱。紀元前填負數年份，例如 -12 表示紀元前 12 年；沒有零年。每年使用相同月長，目前沒有閏年、閏月或多套曆法換算。

月份以排列序號識別。重新排序月份會改變既有事件所對應的月名，調整前請建立快照。

## 編排歷史事件

1. 選擇既有事件，或按「新增歷史事件」。
2. 填事件名稱與歷史摘要，勾選「設定虛構日期」。
3. 輸入年份、月份與日期，按「儲存歷史事件」。
4. 編年事件依日期排列，未定日期的事件列在後方。事件之間的畫面距離不代表等比例時間跨度。
5. 連結場景／世界觀可多選，Windows 按 Ctrl 選取多筆。已連結場景可以直接開啟。

表單必須按「儲存歷史事件」才會寫入；切換前請先儲存。事件刪除沿用「時間線」中的刪除功能。

## 備份與相容性

曆法與虛構日期使用專案 schema v7，包含在 .novel 匯出、快照及副本中；快照比較也能辨識曆法與編年的變更。SQLite 延續既有 JSON 專案保存，不新增資料表。

舊專案開啟後自動補上預設曆法，原有事件保留且列為尚未編年。請在升級前保留一份舊版 .novel；新版輸出檔應使用 0.12.0 或更新版本開啟，不要用舊版程式覆寫含架空歷史的資料。
