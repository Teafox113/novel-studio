# 資料保存與商業化評估

評估日期：2026-10-27。此文件區分本輪開發內容與尚未完成的服務，不代表已通過商店審核或商業驗收。

## 本輪實作：桌面版雙目的地版本備份

在「⋯ → 資料夾與同步備份」分別選擇本機資料夾、Google Drive 電腦版內的資料夾，可只選一個或同時啟用。選擇會保留到下次啟動；停止某個位置的備份不會刪除其檔案。

- 作品的主要工作副本仍為本機 SQLite；此功能不搬移資料庫，也不是直接開啟資料夾內檔案持續編輯。
- 應用程式開啟期間，每分鐘檢查最近成功儲存的作品；有變動才建立新的完整 `.novel` 備份。手動按「立即備份」可強制新增一版。
- 寫入暫存檔、同步到磁碟並回讀核對後才改為 `.novel`。保留舊版本，不覆寫同名工作檔，不自動清除歷史。
- 本機與 Drive 寫入結果分開顯示；失敗的目的地下一輪會再嘗試，成功的目的地不因另一處失敗而重複寫入。
- 若位置失效、權限不足或 Drive 磁碟未掛載，顯示失敗並提醒處理，不宣稱備份成功。
- 這是明文專案備份，資料夾的共享權限會影響誰可閱讀作品。備份檔會累積，請自行管理容量。
- 還原時使用「匯入專案」選取 `.novel`。既有匯入流程會先替目前作品建立安全快照。

Google Drive 電腦版負責將檔案送往雲端。寫入資料夾不等於 Google 已接收；請查看 Drive 電腦版的同步狀態。離線可用性取決於串流／鏡像及離線設定。另一本機副本可避免 Drive 未掛載時完全沒有外部備份。

官方說明：[Drive 串流與鏡像](https://support.google.com/drive/answer/13401938)。

## 下一階段：程式內直接連接 Google Drive

這一階段尚未實作，不能把電腦版同步資料夾宣稱為已完成原生 Drive API 同步。

1. 配置產品擁有者的 Google Cloud 專案、Drive API、OAuth 同意畫面、客戶端與 Picker 設定。桌面與網頁的授權流程分開實作。
2. 採用 `drive.file` 最小必要權限及 Google Picker，讓使用者明確選擇資料夾。選中資料夾不代表取得整顆 Drive 的讀取權限。
3. Refresh token 使用作業系統安全儲存區；不放在 `.novel`、Git 或普通 localStorage。提供取消連接與撤銷授權說明。
4. 建立持久化傳送佇列、離線重試、退避與可恢復進度；用專案 UUID、版本雜湊和遠端檔案 ID 辨識版本。
5. 雙向同步遇到兩端變動時保留兩份並要求選擇／比較，禁止以時間較新為唯一依據自動覆寫。
6. 只有 Drive API 確認且核對遠端版本後才能顯示「雲端已備份」。另提供從雲端選檔及還原預覽。

官方來源：[Drive 權限](https://developers.google.com/workspace/drive/api/guides/api-specific-auth)、[桌面 Google Picker](https://developers.google.com/workspace/drive/picker/guides/desktop-mobile-picker)。

## Chrome 擴充功能是否適合

建議：主編輯器繼續使用桌面版，Chrome 擴充功能作為研究與靈感收集助手。網頁版未來可獨立發展為 PWA，但不應為了上架而將整套桌面程式包進 popup。

| 方向 | 適合程度 | 理由 |
| --- | --- | --- |
| 選取網頁文字、保留網址、加入研究素材 | 適合第一版 | 明確的瀏覽器使用情境，可以少量權限完成 |
| 側邊欄隨手記、挑選作品及分類 | 適合後續 | 與收集用途一致，需要可靠的離線暫存與匯入協定 |
| 整套長篇編輯器塞入 popup | 不建議 | 工作區狹小且容易關閉，無法提供理想的長時間寫作體驗 |
| 依賴擴充背景程序持續同步作品 | 不適合直接照搬 | Manifest V3 service worker 會休眠，須有持久化佇列與事件驅動設計 |

`chrome.storage.sync` 約為 100 KB 總額度、每項 8 KB，不適合小說及附件同步；它只能用於小型偏好設定。作品應使用 IndexedDB／本機檔案與獨立 Drive API 儲存流程。

上架前應具備 Manifest V3 套件、單一用途說明、最小必要權限、隱私權政策、商店資料揭露，以及擴充功能權限／離線測試。只在使用者點選收集時讀取當前頁面，避免預設要求全網站存取。

官方來源：[儲存額度](https://developer.chrome.com/docs/extensions/reference/api/storage)、[背景程序生命週期](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle)、[使用者資料規則](https://developer.chrome.com/docs/webstore/program-policies/limited-use)。以上是產品評估，不保證商店審核結果。
