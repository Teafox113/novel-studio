# 全專案搜尋與快速導覽

Novel Studio 0.8.0 的搜尋會即時讀取目前專案，涵蓋：

- 手稿標題、摘要、正文、狀態、場景 Tag 及關聯人物／地點
- 世界觀名稱、別名、摘要、自訂屬性、關係與 Tag
- 時間事件標題、摘要、故事時間、關聯場景及世界觀
- 研究標題、摘要、筆記、網址、引用資訊、原始檔名與 Tag
- 靈感標題、內容、Tag 與關聯世界觀

所有搜尋都在本機記憶體中完成，不會傳送小說內容或關鍵字。

## 開啟與操作

- 點擊頂端「搜尋專案」，或按 `Ctrl+K`。
- 使用 `↑`、`↓` 選擇結果，按 `Enter` 開啟，按 `Esc` 關閉。
- 點擊類型篩選可只看場景、世界觀、時間線、研究、靈感或文件。
- 結果會顯示命中的欄位與附近原文，開啟後直接定位到對應模組。

## 查詢語法

| 寫法 | 意義 |
| --- | --- |
| `北港` | 搜尋單一關鍵字 |
| `北港 密道` | 結果必須同時包含兩個詞 |
| `"灰塔醫師"` | 將引號內容視為一個完整詞組 |
| `#皇室` | 搜尋 Tag；同時也可命中其他欄位中的同名文字 |
| `type:人物 林晝` | 只搜尋世界觀資料 |
| `類型:研究 航海圖` | 只搜尋研究素材 |

可用類型包含：`場景`、`人物`／`世界觀`、`時間線`／`事件`、`研究`、`靈感`、`文件`。

## 排序原則

名稱與標題的權重最高，其次是別名、故事時間、Tag、摘要、屬性與正文。完全相符、
欄位開頭相符及重複出現會提高排序；同分時較近期更新的資料優先。

目前索引是即時計算，適合本機小說專案且無需資料遷移。未來資料量需要時，可在維持
相同結果介面的情況下切換 SQLite FTS，並額外加入可選的語意搜尋。
