# 打字機專注模式

在手稿中選取場景，於「編輯」畫面按「打字機」。深色書房背景、暖色紙張及印字字體取代原工作區，隱藏工具列與側欄。正文字級沿用顯示設定。

輸入或移動游標時，編輯行自動靠近畫面上方 42% 的位置。中文輸入法組字時暫停跟隨，組字結束再定位。手動捲動閱讀不會自動拉回，直到再次編輯或移動游標。

右上「參考浮窗」開啟既有研究素材庫。可切換右上、右下、左上、左下角，或收合以騰出寫作空間。圖片、PDF、筆記沿用原有預覽；網址提供來源連結，一般文件不新增解析能力。浮窗目前固定寬度，尚無任意拖曳與多份並排。

按 Esc 或「退出專注」回到一般編輯畫面。模式切換共用同一編輯器，保留自動儲存及復原歷史。上方持續顯示儲存狀態。
