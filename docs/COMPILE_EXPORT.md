# Compile／匯出中心

Novel Studio 0.6.0 可以將 Binder 中的手稿組裝成可交稿、閱讀或保存的單一檔案。

## 書稿設定

- 書名、副標題與作者
- 是否加入書名頁
- 是否顯示卷標題及場景標題
- 是否輸出場景摘要
- 只包含指定狀態：構思、草稿、修訂、完成
- 場景間使用留白、`⁂` 分隔符或另起新頁

所有設定只作用於這一次輸出，不會修改原始場景、標題或 Binder 排列。

## 輸出格式

| 格式 | 適合用途 |
|---|---|
| DOCX | 投稿、編輯、校對與交付出版社 |
| EPUB 3 | 電子書閱讀器與電子書平台前置檔 |
| PDF | 固定版面、列印與審閱 |
| HTML | 網頁發布或進一步自訂 CSS |
| UTF-8 TXT | 長期保存、交換及其他文字工具 |

DOCX 內含 Word 樣式、A4 頁面設定及繁體中文字型提示。EPUB 內含書名頁、OPF
metadata、導覽目錄、CSS 和各卷 XHTML 章節。

## PDF 操作

選擇 PDF 後按「列印／另存 PDF」，Windows 會開啟系統列印視窗：

1. 印表機選擇「Microsoft Print to PDF」或「另存為 PDF」。
2. 紙張使用 A4，縮放建議 100%。
3. 確認預覽後選擇儲存位置。

這個流程使用系統繁體中文字型排版，避免自行產生 PDF 時因未嵌入中文字型而出現
空白或方框。

## 目前限制

- 尚未提供出版社範本、封面圖片、頁首頁尾與自訂 EPUB CSS 主題。
- EPUB 尚未整合平台特定 DRM 或 ISBN metadata。
- PDF 需要經過系統列印視窗，尚非背景一鍵輸出。
