# 開發 ROADMAP · 稿紙 C 路線

重建日期：2026-11-12。產品方向：**先讓作者安心、安靜地寫，再把設定與分支整理成書。**

公開安裝版仍為 v0.18.0；下述「開發完成」指目前工作樹，並不代表已打包、推送或上架。上一版清單保留在 [歷史紀錄](history/ROADMAP-before-C-2026-11-12.md)。

## 本輪決策

- 採用 Claude 的 **C「稿紙・留白」**，不是 A/B 混搭：寫作／設定／成書三模式、書脊與可釘住的目錄、稿紙與眉批邊欄。
- 舊作品、.novel、SQLite 與程式 identifier 保持相容；不因換外觀搬動資料。
- 互動分支總覽放在成書；正文下的選項設定仍留在寫作。跨場景查找保留搜尋與來源定位。
- 便條先做「引用選文＋場景連結」，沿用現有 linkedNodeIds；**不是**會隨編輯自動移動的段落錨點。
- 正文與介面字級仍各自獨立；深色主題與專注模式共用色票。
- 不顯示虛構的「今日 +83」。每日淨增統計要先有可處理跨日、刪除、復原與多裝置的統一定義。
- 雲端先做手動備份／還原，再做衝突安全的跨裝置接續；不先做多人逐字共編。

## M1 · 資料安全發布門檻（下一輪優先）

| 順序 | 交付 | 完成條件 |
| --- | --- | --- |
| 1 | 單一寫入者保護 | 第二程序／分頁只能唯讀或明確接手；崩潰後可復原，不靠時間猜鎖失效 |
| 2 | 備份可管理 | 顯示份數與容量，先預覽再清理，保護最近成功版與還原前快照 |
| 3 | 還原與損壞處理 | 截斷、格式不符、磁碟滿、無權限、Drive 離線皆不覆蓋現稿；重試可用 |
| 4 | 保存位置與遷移 | 先複製、核對內容、確認後切換；失敗可回舊位置，記錄兼容版本 |
| 5 | 發布管線 | 可重現建置、授權清單、校驗碼、升級／移除測試；簽章與更新機制另列依賴 |

這些是正式商業品質的必要條件，優先於增加寫作花樣。現有測試通過不等於斷電／磁碟滿真機驗收完成。

## M2 · 寫作體驗深化

| 構想 | 第一個可驗收版本 | 避免過度設計 |
| --- | --- | --- |
| 段落便條 | 以穩定段落 ID 錨定，編輯時映射位置；刪除段落後列為「來源已移除」 | 不用字元索引硬綁；先驗證撤銷、拆段、合段、匯入 |
| 設定就近查看 | 點已連結的人物／變數，開啟可關閉的摘要，不跳離正文 | 先明確標記，不自行猜測所有同名詞 |
| 並排參考 | 足夠寬時與稿紙並排，窄畫面用可調寬浮窗；鍵盤可收合 | 保留 C 案留白，不新增常駐第四欄 |
| 寫作活動 | 每作品的今日淨增與短期寫作目標，清楚處理跨日和復原 | 不把累積字數當今日新增；不做競賽或強制打卡 |
| 便條整理 | 搜尋、依場景篩選、回收區搜尋、引用回到場景 | 先不加入多色貼紙與自由拖曳，避免破壞稿紙閱讀節奏 |
| 可及性 | 對話框焦點陷阱／回焦、鍵盤巡覽、縮放與螢幕閱讀器驗收 | 色彩對比測試只是一部分，不等同全面 WCAG 合格 |

## M3 · 互動書籍，維持編號劇情塊

1. **分支小地圖**：唯讀節點與箭頭先行，顯示起點、結局、孤立塊、未設定目標；點節點回正文。保留編號跳轉，先不做複雜拖線編輯器。
2. **試走診斷**：列出條件不成立原因、變數前後差異、不可達與循環提示；回退必須恢復整份路線狀態。
3. **人物初始狀態匯入**：使用者明確選擇從人物卡產生變數；區分作者設定與本次試走數值，不自動互相覆寫。
4. **句旁便條轉效果**：先挑引用與變數，再選取得／失去／增減；生效時機明確為進入塊、選擇後或指定段落。
5. **讀者預覽匯出**：再決定單檔 HTML／其他格式；測試離線閱讀、路線存檔與內容授權說明。

參考 Ink 的選項／狀態概念，不以 Ink 執行引擎或 .ink 雙向編輯作前提。

## M5 · Google Drive，先備份再接續

| 階段 | 範圍 | 門檻／驗收 |
| --- | --- | --- |
| A | 直接連接自己的 Drive，手動上傳完整 .novel、列版本與下載還原 | Google Cloud／OAuth 用戶端、桌面瀏覽器登入＋PKCE、OS 安全儲存權杖、drive.file／Picker 存取範圍實測；上傳失敗不影響本機 |
| B | 同一作者多裝置接續 | 持久化佇列、重啟續傳、版本／雜湊核對、遠端已改時保留兩份；不能靠最後修改時間覆蓋 |
| C | 增量同步 | 先量測整份快照成本，再選每場景檔或修訂紀錄；索引與場景版本必須一致，可從部分上傳復原 |
| D | 共享資料夾多人不同場景 | 權限撤銷、租約逾時、同時搶占、離線重連都保留衝突；「正在編輯」只是提示，不能保證排他鎖 |
| E | 逐字共編（遠期） | 需要另外選擇通訊、CRDT／OT 與權限架構，不宣稱 Drive API 本身提供共編 |

不需要自建後端不等於不用註冊服務。Drive 桌面版同步仍是目前唯一實作；新 OAuth 功能未完成前不擴大網路權限、不顯示假登入按鈕。

## 暫緩但保留

世界觀關係圖、PDF OCR、更多曆法換算、自訂排版範本、語言模型供應器、行動素材輸入。先以 M1 的資料安全與 M2 的寫作實測決定順序，不讓功能數量取代穩定性。

## 每個里程碑共同完成條件

能從入口走完主要流程；空資料、錯誤與取消都有回饋；舊作品不損毀；有針對風險的測試與明暗／縮放驗收；README 分清「已發布」與「開發版」。發版另需 Windows 原生驗收、安裝／免安裝產物與校驗碼。
