# Novel Studio 0.18.0

2026-10-28 · FloofyFox · Windows x64

- 資料夾備份新增歷史清單（最近 200 份）、作品與差異預覽；還原前先建立目前作品的安全快照，安全快照失敗則停止還原。
- 儲存與還原透過單一工作佇列依序執行，避免較舊的自動儲存蓋回還原結果。
- 尚未儲存或已選資料夾備份未完成時，關閉視窗會提醒。可返回編輯，或明確選擇離開。
- 瀏覽器作品損壞時停止自動載入，保留原始內容。
- 便條紙新增回收區與復原，保留相關連結；記住每部作品的便條位置、收合與選取狀態，Ctrl+Shift+N 可開啟／關閉。
- 整理開發清單，將已完成與待辦分開，移除重複過時狀態。

## 下載與升級

一般使用者下載 `Novel-Studio-0.18.0-Windows-x64-Setup.exe`；免安裝版解壓 `Novel-Studio-0.18.0-Windows-x64-NoInstall.zip` 後執行 `Novel-Studio.exe`。另附 MSI 與 SHA256SUMS.txt。

升級前匯出 .novel 備份並關閉舊版。安裝程式尚未數位簽章；免安裝版需要 WebView2，作品仍存於 Windows 使用者目錄。

## 限制

資料夾備份不自動刪除歷史，保留份數設定、多程序編輯防護與直接 Google OAuth 同步仍待後續。Drive 雲端上傳由 Google Drive 電腦版處理。備份歷史只讀取已選資料夾中的 Novel-*.novel 檔；大型檔案可用匯入專案。便條回收採保留內容方式，尚不提供永久清除。關閉提示不是斷電保護。
