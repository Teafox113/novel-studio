# 研究與素材庫

Novel Studio 0.5.0 提供可與故事資料互相引用的研究工作區。

## 素材類型

- 專案內筆記
- 網頁來源
- PDF
- 圖片
- TXT、Markdown、Word、RTF 等一般文件

## 工作流程

1. 在「研究」左上角按 `＋`，新增筆記、網址或匯入檔案。
2. 補上摘要、摘錄、作者／機構、出版者、出版日期與查閱日期。
3. 使用 Tag 分類用途與查證狀態。
4. 連結引用這份資料的場景，以及相關人物、地點或設定。
5. 世界觀資料右側會反向列出研究來源，可直接跳回素材。

圖片可在工作區預覽；PDF 會嘗試使用目前系統的 WebView PDF 功能顯示，若環境
不支援，仍可使用「另存附件」取回原始檔。

## 可攜性與限制

- 附件以 data URL 嵌入專案，因此會包含在 `.novel` 匯出檔中。
- Windows 桌面版單檔上限 15 MB。
- 瀏覽器原型因 localStorage 容量限制，單檔上限 2 MB。
- `.novel` 匯入檔案上限 100 MB。
- 目前不支援影片、大型音訊、PDF OCR、全文擷取或頁碼級引用。
- 大型素材日後會改用內容雜湊資產目錄，匯出時再封裝進可攜專案。
