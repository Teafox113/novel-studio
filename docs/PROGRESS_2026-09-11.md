# 2026-09-11 開發進度

既有基礎為 0.9.0，研究浮窗、快速收集與可讀性設定已完成。

本次補上路線圖的快照版本比較：開啟「備份與還原」，點選任一備份的「比較」，即可查看備份到目前內容的新增、刪除及修改。展開項目可左右閱讀欄位內容，涵蓋手稿、專案基本資料、世界觀、關係、Tag、連結、靈感、時間線、研究及 AI 審核。

比較忽略更新時間、修訂計數及衍生字數；仍辨識正文格式變更。附件只顯示變更提示，不輸出 base64。此功能是唯讀比較，既有還原前安全備份流程保留。

目前提供欄位級對照，尚無逐字標色或選擇性合併。格式欄位呈現結構化內容。已完成自動測試與網頁正式建置；尚未進行視覺操作驗收或重新打包 Windows 安裝程式，release 中仍為既有版本。

建議下一項：新建、開啟與另存小說專案，先釐清多專案本機儲存及切換時的安全備份流程。
