## 下載與升級

一般使用者下載 `Novel-Studio-0.16.1-Windows-x64-Setup.exe` 安裝。免安裝版請解壓 `Novel-Studio-0.16.1-Windows-x64-NoInstall.zip` 後執行 `Novel-Studio.exe`。

升級前匯出 `.novel` 備份並關閉舊版。免安裝版需要 WebView2，作品保存在使用者目錄，不會隨 EXE 搬移。安裝檔尚未簽署數位簽章。

變數尚未參與分支條件與效果運算；目前試讀依照設定的劇情塊跳轉。
