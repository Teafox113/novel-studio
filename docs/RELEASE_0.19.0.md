# Novel Studio 0.19.0

2026-11-24 · FloofyFox · Windows 10／11 x64

## 這次更新

- C「稿紙・留白」介面：寫作／設定／成書三模式、明暗主題、可收合目錄、稿紙行線與底部工具。
- 反白正文後可直接記成變數或建立摘錄便條；人物設定與匯出前檢查重新整理。
- 修正大倍率介面縮放、標籤與別名輸入、重新開啟作品未選中正文等問題。
- Windows 寫入鎖：同一資料目錄只能開啟一個新版編輯程序，程序結束後自動釋放。
- 匯入／還原其他作品時，同時保護目前作品與即將被覆蓋作品；安全快照失敗就停止。
- 修正同場景還原後編輯器仍顯示舊內容的問題；匯入與還原後重建編輯器，避免下一次輸入寫回舊稿。
- 瀏覽器備份清單損壞時保留原資料並停止建立快照，不會用空清單覆寫。
- 建置改用專案獨立 Cargo 快取，避免損壞的全域套件阻擋建置。

## 下載選擇

- 一般使用者：`Novel-Studio-0.19.0-Windows-x64-Setup.exe`。
- 不想安裝：完整解壓 `Novel-Studio-0.19.0-Windows-x64-NoInstall.zip`，執行 `Novel-Studio.exe`。
- MSI 部署：`Novel-Studio-0.19.0-Windows-x64-zh-TW.msi`。
- `SHA256SUMS.txt` 可核對下載完整性。

## 升級與資料

先在舊版匯出 `.novel`，關閉所有舊版視窗，再安裝或啟動新版。保留原有應用識別與 SQLite 路徑；免安裝版仍使用 Windows 帳號的資料目錄，資料不會跟著 EXE 移動。舊版及瀏覽器分頁不支援本次 Windows 寫入鎖，請勿同時編輯。

本機備份與 Drive 電腦版資料夾備份保留完整版本；Drive 上傳狀態需查看 Drive 電腦版。目前尚無直接 Google 登入、自動雙向合併或多人共編。備份不會自動清理，請留意磁碟容量。

安裝檔尚未簽署數位簽章。PDF 內嵌預覽依 WebView2 支援，無法顯示時可另存附件。Chrome 收集助手仍為試用，尚未上架。

測試範圍與限制見 [發布驗收紀錄](https://github.com/Teafox113/novel-studio/blob/v0.19.0/docs/RELEASE_QA_0.19.0.md)。
