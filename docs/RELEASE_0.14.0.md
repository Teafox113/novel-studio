# Novel Studio 0.14.0 — 遊戲式人物狀態卡

世界觀人物頁新增六類可編輯關鍵字：身分、身體狀態、背包、已知資訊、能力與數值。

- 物品數量、能力／數值及選填上限，顯示進度條。
- 可連結既有世界觀資料與來源場景，並記錄補充說明。
- 支援關鍵字搜尋、編輯、移除及立即復原。
- 人物卡納入儲存、快照比較、專案副本與 .novel 備份。

這是作者設定管理介面；句旁註記轉變數、分支畫布及即時遊玩狀態尚未實作。

## 使用與升級

從「世界觀 → 人物」開啟狀態卡，按分類旁的＋新增，編輯後按「儲存關鍵字」。詳見 [人物狀態卡指南](https://github.com/Teafox113/novel-studio/blob/main/docs/CHARACTER_PROFILE.md)。

升級前先匯出 .novel 備份。資料格式為 schema v8，請勿使用舊版覆寫作品。

下載 Setup.exe 安裝；免安裝選 NoInstall.zip，完整解壓後執行 Novel-Studio.exe。免安裝版需要 WebView2，資料仍在 Windows 使用者目錄，與安裝版共用，請勿同時編輯。安裝檔尚未簽署數位簽章。
