# Novel Studio 0.17.0

2026-10-27 · FloofyFox · Windows x64

- 新增隨手便條紙：多張切換、左右停靠、收合、標題與內容自動儲存，隨作品匯出及備份。
- 新增雙資料夾備份：本機及 Google Drive 電腦版資料夾可單獨或同時啟用；初次設定即備份，之後每分鐘檢查變動，亦可手動備份。
- 每次保留新 .novel 檔，寫入後回讀核對；目的地失敗獨立顯示並可重試，不覆蓋歷史版本。
- 互動選項新增變數條件與效果；試讀顯示狀態、物品不足停用選項，回退還原變數。

## 下載與升級

一般使用者下載 `Novel-Studio-0.17.0-Windows-x64-Setup.exe`。免安裝版請完整解壓 `Novel-Studio-0.17.0-Windows-x64-NoInstall.zip`，執行 `Novel-Studio.exe`。另提供 MSI 與 SHA256SUMS.txt。

升級前匯出 .novel 備份並關閉舊版。新版專案中的互動條件須使用 0.17.0 或更新版本試讀，舊版不會執行規則。

## 使用提醒

- 安裝檔尚未簽署數位簽章。免安裝版需要 WebView2 Runtime，資料仍保存在 Windows 使用者目錄。
- Google Drive 電腦版負責雲端上傳，請在該程式確認同步完成。本版沒有直接 Google 登入與跨裝置雙向合併。
- 資料夾備份僅在程式開啟時運作，退出前可按立即備份。備份會累積且為明文，請自行管理容量與共享權限。
- 便條紙關閉只隱藏，內容保存在目前作品的靈感資料中。
