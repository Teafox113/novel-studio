# Novel Studio

目前版本：0.9.0

為長篇小說、世界觀與研究素材設計的本機優先創作工作空間。

## 目前階段

第一階段互動原型，已包含：

- 三欄小說工作區
- Binder 樹狀結構
- 場景文字編輯
- Corkboard 卡片
- Outliner 表格
- 自訂場景資料與目標字數
- 瀏覽器本機自動儲存
- 世界觀、時間線、研究與 AI 模組入口

第二階段基礎已包含：

- Tauri 2 Windows 桌面程式骨架
- 專屬桌面程式圖示
- SQLite schema 與自動 migration
- 瀏覽器 localStorage／桌面 SQLite 自動切換
- 資料庫載入與儲存失敗提示
- `.novel` 可攜專案匯出與匯入，可在瀏覽器版及桌面版之間交換
- 每日自動備份、手動快照與版本還原
- 備份與目前版本比較：新增、刪除、修改統計與欄位前後對照
- 匯入及還原前自動建立安全備份
- 繁體中文 Windows 安裝程式（NSIS 與 MSI）
- 快照、附件及同步操作的資料表預留
- schema v2 自動遷移，舊版 POV／地點文字會升級為穩定實體連結
- 左側隨手靈感庫：分類、搜尋、Tag、世界觀連結與一鍵轉成場景
- 可擴充的人物、地點、專有名詞、關係與 Tag 資料結構
- 可操作的世界觀資料庫：人物、地點、勢力、物品、設定與專有名詞
- 世界觀全文搜尋、別名、自訂屬性、識別色與 Tag
- 實體關係建立，以及場景／靈感的反向連結與一鍵跳轉
- 雙軸時間線：分開管理故事發生順序與讀者閱讀順序
- 時間事件可連結場景及世界觀，並標示倒敘、插敘或延後揭露
- 新增場景或將靈感轉為場景時，自動建立對應的時間事件
- schema v3 自動遷移，舊專案會由既有場景建立初始時間線
- 研究素材庫：專案筆記、網址、PDF、圖片與一般文件
- 研究來源、作者／機構、出版／查閱日期與工作筆記
- 研究素材可連結 Tag、場景與世界觀，世界觀可反查研究來源
- 附件嵌入專案並跟隨 `.novel` 移動，桌面版單檔上限 15 MB
- schema v4 自動遷移與 100 MB 可攜專案匯入驗證
- Compile 匯出中心與即時書稿預覽
- DOCX、EPUB 3、HTML 與 UTF-8 純文字直接匯出
- 透過系統列印版面輸出繁體中文 PDF
- 書名頁、卷標題、場景標題、摘要、稿件狀態與分隔規則
- DOCX／EPUB 封裝會由獨立 ZIP 與 XML 解析器自動驗證
- 完全本機的 AI 協作審核中心，不傳送小說內容到網路
- 場景摘要、人物年齡事實與本文提及候選
- POV、地點、故事時間缺漏與年齡／別名一致性提示
- 每項建議保留來源引文、變更前後預覽及接受／略過紀錄
- schema v5 保存審核指紋與決定，重新掃描不會反覆提出已處理項目
- 全專案即時搜尋：正文、摘要、人物、地點、別名、屬性、關係、時間線、研究與靈感
- Tag、關聯人物／地點、研究來源與原始檔名都可搜尋，並依欄位重要性排序
- `Ctrl+K` 快速開啟，支援多關鍵字、引號詞組、`#Tag` 與 `type:人物` 類型限定
- 搜尋結果顯示命中欄位與上下文，可用鍵盤直接跳到原始資料
- 寫作區研究浮窗：搜尋、翻閱圖片／PDF／網址／筆記、調整寬度、釘選及連結目前場景
- 快速收集：文字、網址、圖片、PDF 與文件直接貼上或拖入，不必預先選擇分類
- 文字自動進入靈感庫，網址及附件自動進入研究素材；重複來源會沿用既有資料
- 靈感可直接貼入圖片或網址，附件只保存一份並以 schema v6 雙向連結研究素材
- 顯示設定提供 100%、110%、125% 介面縮放與 15–24px 小說正文字級
- 打字機專注模式：暖紙墨字、深色書房、游標行自動捲動與 Esc 返回
- 專注模式研究浮窗可放在四個角落並收合，持續參照既有筆記、圖片及 PDF

## 瀏覽器原型

```powershell
npm install
npm run dev
```

## 桌面程式

桌面建置需要 Rust、Microsoft C++ Build Tools 與 Windows SDK。

```powershell
npm run desktop:dev
npm run desktop:build
```

本機已安裝 Rust、Microsoft C++ Build Tools 與 Windows SDK，並已成功驗證
Windows 原生建置。執行 `npm run desktop:build` 即可產生桌面程式。

一般使用者不需要安裝開發工具。請執行 `release` 資料夾中的 Windows Setup，
安裝完成後即可從開始功能表開啟 Novel Studio。

## 在另一台電腦繼續寫

1. 在原電腦開啟右上角「專案與備份」。
2. 選擇「匯出專案」，產生單一 `.novel` 檔。
3. 將 `.novel` 檔複製到 USB、Google Drive 或 OneDrive。
4. 在另一台電腦安裝 Novel Studio。
5. 開啟「專案與備份」並選擇「匯入專案」。

匯入前，程式會先替目前內容建立安全備份。完整說明請見
[`docs/USING_ON_ANOTHER_PC.md`](docs/USING_ON_ANOTHER_PC.md)。

## 技術方向

介面以 React、TypeScript、Vite 與 Tiptap 建立；Tauri 2 提供桌面原生殼，
SQLite 保存桌面版小說資料。瀏覽器開發模式繼續使用 localStorage，兩者共用相同
的領域模型與畫面元件。
