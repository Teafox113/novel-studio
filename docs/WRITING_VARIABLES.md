# 關鍵詞快速收集與變數庫

## 不打斷寫作的收集方式

1. 在小說正文反白關鍵詞，例如「黃銅鑰匙」。
2. 在反白範圍按右鍵，選「加入互動變數」。也可用 Shift+F10 開啟關鍵詞選單。
3. 出現「已加入變數庫，可稍後設定」後即可繼續打字，不會彈出設定表單。
4. 同名變數會沿用，並增加這次引用。不同寫法可用「連結既有變數」搜尋並選取。

不需要先啟用互動分支模式。一般寫作及打字機模式皆可收集。已連結文字上可開啟「查看變數」。右鍵未選取關鍵詞且沒有引用時，保留一般選單。

## 稍後整理

在寫作區按「變數庫（待設定 N）」或從「互動書籍」開啟變數庫。可搜尋名稱／說明，篩選全部、待設定與已設定。

可補齊名稱、類型（物品／資訊／數值／狀態）、所屬人物、初始值及說明。物品數量為非負整數；資訊與狀態為起始已知／啟用或否。未決定時選「稍後設定」。

按「儲存草稿」保持待設定；選好類型後按「儲存並完成設定」。細節表單需手動儲存，離開前請保存；快速收集本身自動納入專案儲存。

## 原文引用

引用有淡底線，可取消「顯示變數標記」隱藏，不影響資料。變數庫保留收集時的關鍵詞與附近原句，可按「定位原文」返回目前的引用文字。

標記隨文字編輯更新。原文標記刪除、復原收集操作或來源場景移除後，變數紀錄仍保留並顯示待重新定位，不會以相同詞句猜測另一個位置。可重新反白文字並連結既有變數；舊來源保留作為紀錄。剪貼或跨文件搬移後，請檢查來源連結並視需要重新引用。

一般書稿匯出不包含標記與變數設定；.novel 備份則保留變數與引用。

## 本版範圍

這版完成快速收集及設定管理。變數的初始值與說明尚未接入人物卡、條件選項或試讀運算；「提及鑰匙」不等於自動取得鑰匙。選擇後取得／消耗、段落效果與生效時機仍待下一階段。

資料格式為 schema v10，需使用 0.16.0 或更新版本。升級前匯出 .novel 備份，勿用舊版覆寫。
